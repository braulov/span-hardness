# S — Exact input-profile compression across NONCOMMUTING abelian segments

Research checkpoint, 2026-10-28. **Status:** unconditional deterministic algorithms, exact counting and a finite-group subset-sum sparse-witness lemma, all with proofs. These are structural algorithms for permutation group programs and some oblivious BPs, NOT an unrestricted polynomial-size LGS algorithm, NOT a general LGS-to-Set-Cover reduction, and NOT a proof of NEXP not in L/poly. Underlying finite-state group-algebra and subset-sum ideas have existing literature; novelty NOT established. This branch inherits R, Q, P and previous LGS notes.

## 0. The key improvement over R

R had abelian pieces all lying in ONE fixed subgroup H, separated by r exceptional nonabelian occurrences, and obtained a 2^{O(r)} solver. The new theorem permits any number of **different** abelian subgroups H_j, which may be pairwise noncommuting in the ambient group. Instead of charging the number of separators/blocks, it charges the size of the abelian **subgroup generated by the joint input profiles**. This subgroup can have size 3^k with k<<p even when there are polynomially many noncommuting subgroup changes.

## 1. Main theorem for a group program

Let G be a fixed finite group, in particular A5 in its five-point permutation action. A group program is a word W(x) of L instructions, each a group element depending on one x_i ∈{0,1}. For a general permutation BP with baseline instructions g_t(0), g_t(1), first apply the exact baseline normalization from branch Q to obtain

    W(x) = (product_t h_t^{x_{i_t}}) * A,

where h_t is its normalized delta and A is the total zero-input baseline. The constant suffix A is included in the final target test.

Partition the normalized delta word into m **consecutive** nonempty segments such that all deltas inside segment j commute pairwise. Write H_j≤G for the abelian subgroup generated by its deltas. The subgroups H_j need not commute with each other. For every variable i define

    g_{ji} = product of h_t over positions t in segment j with i_t=i ∈ H_j,

taking products in any order (they commute inside H_j). Then the segment product on input x is

    F_j(x) = product_i g_{ji}^{x_i}.

Associate to every variable its **input profile**

    v_i = (g_{1i},...,g_{mi}) ∈ Λ = H_1 × ... × H_m,

and let K = <v_1,...,v_p> ≤ Λ be the generated finite abelian subgroup. The map

    Φ(z_1,...,z_m) = z_1 z_2 ... z_m A ∈ G

is generally **not a homomorphism** since H_j may not commute across segments. Nevertheless

    W(x)=Φ(v_1^{x_1} ... v_p^{x_p})

holds exactly, pointwise.

**Theorem S1 (unconditional exact counting).** For any target set T⊆G, one can compute the exact integer #\{x∈{0,1}^p:W(x)∈T\}, as well as find a witness if it exists, in deterministic

    O(poly(L,p,log|G|) * |K|)

arithmetic operations on O(p)-bit integers. In particular, if G is constant and ρ=log_2 |K|=o(p), this is a deterministic 2^{o(p)}poly(L,p) algorithm; L can be p^{100}.

Proof: maintain a dictionary D_i:K→ℕ of counts for profiles from the first i Boolean choices. Start D_0(1_K)=1. For each i set

    D_{i+1}(z) = D_i(z) + D_i(z v_i^{-1}).

At most |K| states appear. Building profiles requires O(L), or poly(L,p) for naïve input. At the end, test Φ(z)∈T for every reachable z and add its D_p(z). All group multiplications, comparisons and evaluations take poly(L,log|G|) time; D_p(z)≤2^p has O(p) bits. Backpointers recover an input. One need not construct the whole K: maintain only reachable profiles in a hash table; their number is at most |K|. QED.

**Important nuance:** Φ is NOT homomorphic, so replacing K with a target subgroup in G and collapsing the segments to their total product is generally unsound. The DP tracks FULL profiles in the product abelian group Λ; only at the end are components multiplied in G's original order.

**Baseline variation:** Without explicit normalization, a segment may contain original pairs g_t(0),g_t(1) all pairwise commuting within that segment. Then write F_j(x)=A_j∏_i(g_{ji}(0)^{-1}g_{ji}(1))^{x_i}, and define v_i by the ratios in H_j. The final evaluation is Φ(z)=∏_j A_j z_j (with the A_j in their respective original positions), NOT ∏_j z_j times a common suffix. The same theorem applies.

## 2. Rank formula and elementary-abelian special cases

Suppose every H_j is elementary abelian of the SAME prime exponent q ∈{2,3,5}, with H_j≅F_q^{d_j}. Flatten each input profile v_i to a column vector in F_q^D, D=Σ_j d_j. Let M be the D×p matrix of all those columns, and k=rank_{F_q} M. Then

    |K| = q^k,

so Theorem S1 gives

    #ProgramSat in q^k poly(L,p)

**deterministically and exactly**. For the R setting H_j=<a>≅C3, the matrix entries are the counts modulo 3 of each ordinary bit's a-contribution to each segment; allowing b exceptional variables fixed separately gives a total 2^b 3^k poly(L,p) algorithm. Here r can be enormous.

For mixed prime exponents q_j, K is a finite abelian group. One may track K directly, without defining one common field rank. For A5 the abelian subgroups are (subgroups of) cyclic C3, C5, cyclic C2, or V4 ≅ F2^2, so K can be decomposed into prime-primary components and |K|=2^{k_2}3^{k_3}5^{k_5}; the ranks are obtained by ordinary linear algebra on the corresponding profile coordinates. Even if a variable has components in several primes, the subgroup of Λ generated by its profiles still has that primary decomposition; **do not replace |K| by an unjustified product of the ranks of separate column projections**: those projections are independently generated by integer multiples of profiles because their group orders are pairwise coprime, so *for subgroups* K=K_2×K_3×K_5 indeed holds. The set of attainable BOOLEAN subset sums need not factor across the different primary components; the joint-profile DP remains necessary.

## 3. Sparse witness via finite-field group algebra

For elementary abelian K≅F_q^k with q prime, the following is a useful stronger existence statement.

**Lemma S2 (Davenport bound).** Every multiset of (q−1)k+1 elements of F_q^k contains a NONEMPTY submultiset summing to zero.

Self-contained proof: consider the group algebra F_q[K]. Let X_1,...,X_k denote its standard coordinate group elements and set t_j=X_j−1. Because (1+t_j)^q=1+t_j^q and X_j^q=1, there is an algebra isomorphism

    F_q[K] ≅ F_q[t_1,...,t_k]/(t_1^q,...,t_k^q).

Every factor 1−X^v lies in the augmentation ideal J=(t_1,...,t_k). But J^{(q−1)k+1}=0, since every monomial of such high total degree has some variable exponent ≥q. Thus for any v_1,...,v_s with s=(q−1)k+1, the group-algebra product ∏_i(1−X^{v_i}) is zero. Its identity coefficient equals

    sum_{I⊆[s], sum_{i∈I} v_i=0} (−1)^{|I|} = 0 in F_q.

The empty I contributes 1. Therefore some nonempty I has zero sum. QED.

**Corollary S3 (pointwise sparse witness).** If a group program from S1 has elementary abelian profile group K≅F_q^k, then for ANY input x there exists x' with at most (q−1)k ones, such that W(x')=W(x) exactly. Indeed iteratively delete nonempty zero-sum subsequences from the set of currently selected profile vectors; each deletion preserves the full profile and thus program output. In particular, for q=3 an accepting input can always be chosen with ≤2k ones, and for q=5 with ≤4k ones.

This is NOT by itself the fastest SAT algorithm: enumerating all ≤(q−1)k supported inputs costs p^{O(k)}, whereas the DP above costs q^k poly(L,p). S3 is a strong structural witness theorem, not a claim of universal fixed-core deletion.

## 4. Characteristic-two strengthening: exact variable deletion

If K≅F_2^k, select k original input profiles v_{i_1},...,v_{i_k} constituting a linear basis of K (Gaussian elimination). Then:

1. Every profile achievable from ALL p input bits is achievable with every nonbasis bit fixed to ZERO.
2. Every profile has exactly 2^{p−k} original preimages, since the map F_2^p→K is a surjective linear map of rank k.
3. Thus satisfiability is preserved by permanently setting p−k bits to 0; the **exact count of accepting assignments** equals 2^{p−k} times the number of accepted assignments on these k retained bits.

This is a deterministic input-sparsification/kernelization for this structural subclass. The same direct basis deletion fails for q=3: two variables with the identical nonzero profile v have attainable values {0,v,2v}, but either individual variable alone only attains {0,v}.

## 5. Genuine extension of previous branches, with test example

Construct a width-five A5 word with p=25 ordinary switches, m=80 segments, each segment j made from a possibly different conjugate 3-cycle a_j. Choose two arbitrary vectors r_1,r_2∈F3^25, and define the row of coefficients of segment j to be α_j r_1+β_j r_2, with α_j,β_j∈F3. Define segment j to contain the 25 factors a_j^{(α_j r_1[i]+β_j r_2[i])x_i}. All within-segment factors commute, while different a_j may not commute. The full 80×25 profile matrix has rank≤2, hence |K|≤3²=9. Its expanded word has 2000 instructions, and its exact accepted-assignment counts are computed with at most 9 profile states, despite up to 2^{25} original assignments.

The earlier R algorithm (single fixed H plus exceptional separator occurrences) does not apply directly: the successive H_j are distinct noncommuting subgroups. The Q component algorithm is also ineffective if the 25 variables form one noncommutation component, as is typical when the a_j vary sufficiently.

Local regression:
- 500 random permutation programs with 1–8 variables and up to 13 segments of commuting 3-cycle factors, comparing the exact output *histogram* against full enumeration, all passed.
- The 25-switch / 80-segment / 2000-instruction example above produced 9 reachable profiles and exact total count 2^25.
- 960 independent random low-rank cyclic-order-2/3 spine programs with up to 20 exceptional factors were compared exhaustively against brute-force accepted counts, all passed; q=2 basis deletion and q=2,3 sparse-witness claims were checked.
These are finite sanity checks, not proofs of literature novelty or of a general LGS reduction.

## 6. Extension beyond permutation programs

Let a layered oblivious deterministic width-w branching program have per-layer transition maps g_t(0),g_t(1):[w]→[w], NOT necessarily permutations. Partition its layers into consecutive segments so that **all maps g_t(0), g_t(1) in a given segment commute pairwise**, as elements of the finite transformation monoid T_w.

For each variable i and segment j, define h_{ji}(b) as the product of all the maps at i-controlled layers in that segment, with x_i=b. Define the two choice-profiles v_i(b)=(h_{1i}(b),...,h_{mi}(b)) in the product of finite **commutative monoids** Λ. Then

    W(x)=Φ(product_i v_i(x_i)),

where Φ multiplies the segment values in their ORIGINAL order. An analogous exact-counting DP updates each profile state by multiplication with v_i(0) or v_i(1). With \(\mathcal M\) the finite commutative monoid generated by all these profiles, the time is O(|\mathcal M|poly(L,p)). No inverses or baseline permutations are required. This extends the formal tool to noninvertible oblivious BPs, although the structural monoid-size bound may be exponentially large.

General non-oblivious BPs whose layer queries depend on the current state do not meet the 'one input bit per layer' premise without additional compilation; this does NOT establish a fast general L/poly verifier SAT algorithm.

## 7. Main barrier and next test

Every A5 program can be partitioned into singleton segments, but then the profile group K can encode all p input bits (|K|≥2^p), giving no speedup. The NP-hard star gadgets from branch R have a natural decomposition with one ordinary bit factor isolated between exceptional y factors; their F3 profile matrix has rank p after splitting at y occurrences if each ordinary bit appears at least once. Thus no general o(p) bound on the profile rank follows from group structure alone.

The parameter \(\rho=\log_2|K|\) depends on the chosen abelian segmentation. Merging adjacent commuting segments can only reduce |K| (the multiplication map of their abelian coordinates is a homomorphism); but choosing WHICH overlapping commuting segments to merge can create different final ranks. **Next real problem:** algorithmically select a segmentation minimizing ρ, or prove a nontrivial rank bound for a syntactically/semantically broad class including non-solvable Barrington programs.

Also study whether **richer summaries of a noncommutative block** can be factored through an abelian profile group WITHOUT violating the NP-hard star example. Low rank of the raw segment profile is sufficient, but not necessary, for rapid satisfiability.
