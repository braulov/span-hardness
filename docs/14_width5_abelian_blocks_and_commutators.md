# Width-five permutation-program SAT: commutators and abelian-block compression

Research checkpoint, 2026-10-29. These are elementary exact derivations, not claims of independent novelty. The target is an input-efficient SAT algorithm for polynomial-length permutation branching programs (PBPs). Width five already captures nonuniform NC1 (Barrington), while unbounded polynomial width is relevant to L/poly. The reduction PBP-SAT -> literal graphic connectivity LGS preserves all primary input bits.

## Exact gauge normalization

For a length-T program with step g_t(x_i) in a fixed finite group G <= S_w, set a_t=g_t(0), d_t=a_t^{-1}g_t(1), Q_t=a_1...a_t, and h_t=Q_t d_t Q_t^{-1}. Then, **for every assignment**, the program value is

    P(x) = h_1^{x_{i_1}} h_2^{x_{i_2}} ... h_T^{x_{i_T}} A,  A=Q_T.

All products retain their order; x_i ∈ {0,1}. We tested the identity on 100 randomly generated programs with all assignments enumerated for p <= 5.

## Abelian-block theorem

Greedily partition normalized word h_1,...,h_T into maximal consecutive blocks in which all h_t commute pairwise. Such a partition with minimum number r of consecutive abelian blocks is found by taking each longest valid prefix. Let H_j be the group generated by the j-th block, abelian by definition.

Within block j, collect all occurrences for variable i into a_{i,j}= ordered product of h_t from that block with label i; any order agrees since H_j is abelian. Therefore

    W_j(x)=prod_i a_{i,j}^{x_i}.

Define a_i=(a_{i,1},...,a_{i,r}) in K = H_1 x ... x H_r. The joint outcome tuple W(x) lies in the subset-product set

    R_0={(1,...,1)}
    R_i=R_{i-1} union {v*a_i : v in R_{i-1}}.

The group K is abelian, so this recurrence represents exactly all possible tuples (W_1(x),...,W_r(x)) across all shared primary variables. At the end inspect whether any reachable tuple (z_1,...,z_r) has z_1...z_r A satisfying the program acceptance condition.

Time O(T+(p+r)|K|) up to constant-width group operations and bookkeeping, and |K|=prod_j |H_j|. For S5 each abelian H_j has order at most 6 (possible orbit partitions: 5, 4+1, 3+2, 2+2+1, etc.). Thus time O(T+(p+r)6^r). Combine with trivial 2^p time as desired. In particular r=O(log p) gives polynomial time and r=o(p) gives subexponential in p for T=poly(p).

This handles arbitrary repeated/interleaved variable reads between blocks. The groups of DIFFERENT blocks need not commute, and the final product must respect block order.

We compared exact reachable output sets on 120 random programs consisting of 1-4 conjugated abelian blocks (with p<=7) against brute-force enumeration; all matched. This is supporting computational evidence, not a novelty claim.

## Example outside both previous tractable parameters

Let a=(1 2), b=(2 3) in S5 and

    W(x)=a^{x1} ... a^{xp} b^{x1} ... b^{xp}.

The ordinary read-order variable liveness is p; the variable noncommutation interaction graph is complete: every variable has one a and one b occurrence, and [a,b]!=1. Nevertheless the word has r=2 consecutive abelian blocks and SAT takes O(T+36p) using the theorem.

## Group convolution/Fourier interpretation

The DP computes positive subset-convolution in the abelian group K. Equivalently, for group characters chi in K-hat, the Fourier transform of the counting distribution satisfies

    Fhat(chi)=prod_i(1+chi(a_i)),

with inversion yielding exact counts of joint block outputs. This factorization generally FAILS for arbitrary noncommutative interleavings of repeated variables; applying group Fourier transforms to S5 alone does not solve global input-consistency.

## Variable commutation-components algorithm (second exact parameter)

Build a graph on primary variables, placing i-j when SOME normalized h_s at i and h_t at j fail to commute. Let the connected components be C_1,...,C_k and let c=max |C_j|.

For two different components all group factors commute. Thus the complete word can be regrouped componentwise, without changing its value for any x:

    W(x)=W_{C_1}(x_{C_1}) ... W_{C_k}(x_{C_k}).

Enumerate the 2^{|C_j|} assignments per component and collect achievable group products U_j subset G. Combine reachable group elements by a DP with at most |G| states. Time O(T 2^c + k |G|^2), for fixed G. For width five, |G| <=120. Checked against 200 random small programs and complete assignment enumeration. This algorithm complements the abelian-block bound: for generic inputs one of c or r may be large.

Important obstruction: if all normalized factors generate A5 or S5 and all nontrivial variables matter, the variable noncommutation graph must be connected. Indeed distinct component-generated subgroups centralize one another and are each normal in their product. A5 and S5 do not decompose into two nontrivial commuting normal subgroups (centralizer of A5 in S5 is trivial). Thus c=p in this hard full-group situation, even though read-once PBPs can still be easy.

## Barrington commutator / next algorithmic problem

Choose noncommuting a,b in A5. The word [a^x,b^y]=a^x b^y a^{-x}b^{-y} is identity unless x=y=1. Nested commutators underlie Barrington's composition of AND gates, illustrating why a bounded total number of abelian blocks is a real restriction rather than merely a change of notation.

We now have three tractability regimes: few live variables in read order; few abelian consecutive blocks in normalized word; small components of variable noncommutation graph. A substantive next step would be to compress *nested commutator structure* in width-five words without expanding every gate into its four word copies, preserving input identity and achieving an input-efficient SAT speedup. No such universal algorithm is proved.
