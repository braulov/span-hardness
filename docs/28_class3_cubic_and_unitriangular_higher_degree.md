# Checkpoint 28 — Cubic class-three discrepancy, and quartic UT5 / fixed-depth unitriangular contraction

Date: 2026-10-29. Self-contained deductions and brute-force checks. **Novelty not established.** This checkpoint extends docs/26_class2_quadratic_cutrank_and_rank_barrier.md and docs/27_vector_quadratic_central_discrepancy.md. It is a STRUCTURAL #SAT algorithm for two-sweep branching programs, not a universal input-efficient PBP-SAT algorithm and not a circuit lower bound.

## Model and conventions

A deterministic two-sweep BP has p primary Boolean variables, width w, first-sweep transitions A_i^0,A_i^1 ∈ S_w applied for i=1,...,p, and arbitrary deterministic second-sweep transitions B_i^0,B_i^1:[w]→[w] applied in a permutation order σ. When transformations are applied to state vectors, products read right-to-left: applying A_1 then A_2 results in A_2 A_1. Put

  U(x)=A_p^{x_p}...A_1^{x_1},
  ~U(x)=A_{σ(p)}^{x_{σ(p)}}...A_{σ(1)}^{x_{σ(1)}},
  E(x)=U(x)~U(x)^{-1}.

The correction acts on the LEFT of the reordered state: U(x)(s0)=E(x)(~U(x)(s0)). For every assignment E(x)∈[G,G] where G is the group generated by first-sweep transitions, because U and ~U have the same factors in different orders.

## A. Class-three theorem: cubic correction

Assume γ4(G)=1 and γ2(G)=[G,G] is explicitly coordinatized as an elementary abelian group F2^c; write z(q) for the group element of coordinate vector q. Then

  E(x)=z(Q(x)),
  Q(x)=q_∅ + Σ_i a_i x_i + Σ_{i<j} b_ij x_i x_j
        + Σ_{i<j<k} c_ijk x_i x_j x_k
        ∈F2^c.

PROOF of degree ≤3. Fix any adjacent-swap sequence transforming the factor list 1,...,p into σ. Swapping factors depending on two Boolean bits introduces a commutator in γ2. Each inserted commutator is conjugated by some other first-sweep factors. In a class-three group, γ3 is central, γ2 is abelian, and the conjugation of a γ2 commutator by a product of factors is the original commutator times central triple commutators depending on at most one additional bit each. Every swap contribution therefore depends on at most three distinct input bits. The product of contributions is additive in the elementary-abelian γ2 coordinates; consequently each coordinate has Boolean ANF degree at most three. This proof allows BOTH choices A_i^0,A_i^1 to be nonidentity and arbitrary.

An algorithm obtains all ANF coefficients by evaluating E(1_S) on subsets S⊆[p], |S|≤3 (O(p³) evaluations) and Boolean Möbius inversion. For a coefficient c_S,

  c_S=Σ_{T⊆S} z^{-1}(E(1_T)) (mod 2).

This is polynomial when first-sweep permutation operations and γ2 coordinate conversion are polynomial-time.

## B. Generic residual-polynomial cutrank lemma

Suppose a correction E(x)=φ(Q(x)) has a vector-coordinate map Q:{0,1}^p→F2^c whose complete multilinear ANF is known, degree ≤D=O(1), and φ is an efficiently evaluable lookup from coordinate vectors to group transformations. **φ need not be a homomorphism**. Reindex variables into second-sweep order, and write Q(x)=Σ_{S⊆[p], |S|≤D} q_S x_S.

For each chronological cut t define matrix K_t over F2:
- rows: nonempty past monomials x_I, I⊆[t], 1≤|I|≤D−1;
- columns: nonempty future monomials x_J, J⊆{t+1,...,p}, 1≤|J|≤D−1, EACH with c coordinate columns;
- row I, future-monomial J contains the c-bit coefficient q_{I∪J} if |I∪J|≤D, zero otherwise.

More precisely concatenate the c coordinate bits horizontally to obtain a standard binary matrix. Put r=max_t rank_F2 K_t.

After reading past assignment a, define q=Q(a,0_future) and residual polynomial R_a(y)=Q(a,y)−Q(a,0). The prefix-dependent part of R_a lies in the row span of K_t, hence there are at most 2^r possible residual polynomials at any cut (the prefix-independent 'pure future' contribution is fixed).

Given next bit b, obtain the NEW q and R via ordinary polynomial restriction:
  δ=R_a(b,0);
  q' = q + δ;
  R'(y)=R_a(b,y)−δ.

A weighted read-once DP processes second-sweep variables and tracks:
1. reordered-first-sweep state u∈[w] starting from original s0;
2. second-sweep state v∈[w] starting from guessed true middle state z0∈[w];
3. correction coordinate q∈F2^c;
4. residual polynomial R (≤2^r possibilities).
At end require z0=φ(q)(u) and v∈Accept. Each actual assignment has exactly one matching guess z0. Thus exact #accepted inputs and satisfiability are computed in

  time 2^{O(c+r)} poly(p^D,w)

when φ and the ANF are efficiently evaluable. The state bound is O(w³ 2^{c+r}), plus polynomial-length arithmetic on exact integer counts. For c+r=o(p) and D fixed this is input-efficient 2^{o(p)}poly(p,w).

**Important algorithm-engineering detail:** K_t must be built with only the O(p^{D−1}) actually possible future monomials as columns. Using the numerical value of a bitmask as a column index would allocate exponentially huge integer bit vectors and would NOT be a polynomial-time implementation. The independent checker uses compressed monomial indexing.

## C. Genuine cubic example

Let G=UT4(F2) (order 64, nilpotency class 3), with standard generators
  X=I+E_12, Y=I+E_23, Z=I+E_34.
Choose first-sweep transitions (identity,X),(identity,Y),(identity,Z) and second order σ=(2,1,3), one-based.

Then E(x) has nonzero γ2 coordinates exactly
  q_(1,3)=x1*x2,
  q_(1,4)=x1*x2*x3,
(with q_(2,4)=0 in the chosen multiplication convention).
In particular, the cubic term is genuinely nonzero.

The UT4 group acts faithfully on 16 states of F2^4 by its natural linear action; the arbitrary second sweep can act via ANY deterministic maps on those same 16 states. We compared the exact residual DP against brute-force #SAT for 400 random width-16 programs with p≤8, including arbitrary A_i^0,A_i^1 and arbitrary irreversible second transitions. Every count matched, and every computed cubic ANF was cross-checked on all 2^p assignments.

## D. Extension beyond class three: UT_d(F2)

For fixed d≥3, let first-sweep transitions be given as matrices in UT_d(F2), acting by permutations on the same w-state space as the second sweep. (An explicitly given group action is required to apply the correction to the state.) Let c=(d−1)(d−2)/2, the number of upper-triangular positions of distance at least two. Since E(x)∈[UT_d,UT_d], its first superdiagonal entries vanish. Represent E(x) by the vector Q(x)∈F2^c of its remaining c entries.

CAUTION: for d≥5, the commutator subgroup is generally NONABELIAN. The coordinate map E↦Q is not a homomorphism, and **we do not need it to be**. We calculate the entire matrix E(x) and its coordinate polynomial; the group element is reconstructed only at the final state-consistency check.

Each entry (i,j) of a product of upper unitriangular d×d matrices, whose individual entries depend on a SINGLE Boolean bit, has Boolean degree at most j−i. Every nonzero contribution follows a strictly increasing index chain i<i1<...<j with at most j−i nonidentity factors. The inverse of the reordered product is also a product of upper unitriangular matrices, each depending on one bit. Therefore each coordinate of E(x)=U(x)~U(x)^−1 has Boolean degree ≤d−1.

We can recover every ANF coefficient with O(p^{d−1}) evaluations at Hamming-weight ≤d−1 assignments, using Möbius inversion. Let r_d be the maximum cutrank of these vector polynomial coefficients as in Section B, with D=d−1. Then

  #TwoSweepBPSAT ∈ 2^{O(c+r_d)} poly(p^{d−1},w)

for fixed d, with arbitrary second-sweep order, arbitrary irreversible second-sweep transitions and w allowed to be polynomial.

In UT5(F2), c=6 and D=4, so #SAT is 2^{O(6+r4)}poly(p,w). This is a genuine CLASS-FOUR result and requires no abelian commutator subgroup.

## E. Genuine quartic example and experiments

In UT5(F2) choose four generators
  X=I+E_12, Y=I+E_23, Z=I+E_34, W=I+E_45,
with identity 0-transitions. Reorder [X,Y,Z,W] to [Y,X,Z,W]. In our convention, E(x) has nonzero entries:
  E_13=x1*x2,
  E_14=x1*x2*x3,
  E_15=x1*x2*x3*x4.
The fourth-degree term is genuinely nonzero. Here E(x) lies in a potentially nonabelian subgroup [UT5,UT5].

The natural action on F2^5 gives width w=32. We checked 175 random two-sweep width-32 programs with 1≤p≤7, random UT5 first-sweep matrices (both choices independent), random irreversible second-sweep transitions and random second-pass permutations: exact #SAT from the quartic residual DP matched exhaustive enumeration. For every random instance, the reconstructed ANF agreed with all 2^p group discrepancies.

The same UT5 model using the increasing-oscillation second-read permutation and repeating the four adjacent generators produced observed cutrank values between 4 and 9 for p≤24, always with nonzero quartic terms for p≥8. This is *experimental evidence only*, not a proof of bounded cutrank as p→∞. Also, this particular permutation has bounded displacement from identity, so existing order-interface DPs may handle it without nilpotent algebra; do not overclaim a new unconditional separation.

## F. Prior art and limits

- Goldmann–Russell and subsequent literature establish polynomial-time ProgramSat over FIXED finite nilpotent groups. See Idziak, Kawałek, Krzaczkowski, Weiß, ICALP 2022, https://doi.org/10.4230/LIPIcs.ICALP.2022.127. The model HERE differs: only the FIRST pass is required to lie in a nilpotent matrix group, while the SECOND pass consists of arbitrary deterministic maps sharing the same primary bits in an arbitrary order. Our theorem should not be misrepresented as a new algorithm for ordinary nilpotent-group ProgramSat.
- Standard commutator collection: Clement–Majewicz–Zyman, *The Theory of Nilpotent Groups*, chapter on collection and basic commutators; see https://ideas.repec.org/h/spr/sprchp/978-3-319-66213-8_3.html.
- For nonuniform polynomial-width BP-SAT as needed for the L/poly circuit-lower-bound goal, restriction to a fixed-depth unitriangular first sweep is still extremely narrow. No universal 2^{o(p)} algorithm follows, nor any NEXP circuit lower bound.
- Quantitative extension to GROWING d: interpolation uses Σ_{j≤d−1} binom(p,j) ≤ p^{O(d)} evaluations, and Gaussian elimination on coefficient-matrix dimensions p^{O(d)} also takes p^{O(d)} time. The full algorithm therefore runs in

    2^{O(r_d+d²+d log p)} poly(p,w)

  (assuming polynomial-time matrix group actions). In particular, if d=O(log p), then c=O(log² p) and construction overhead 2^{O(log² p)}=2^{o(p)}. Thus r_d=o(p) SUFFICES for 2^{o(p)}poly(p,w) EVEN WITH LOGARITHMICALLY GROWING MATRIX DIMENSION. The natural faithful action of UT_d(F2) on F2^d has width w=2^d=poly(p) in this regime. This is a parameterized condition, not a universal upper bound on r_d. For d much larger, interpolation and the c-dimensional correction may be too expensive.
- Finding a novel and useful family with intrinsically LARGE reordering complexity but r_d=o(p), not simply small displacement or separable order, remains a meaningful next test.
- Priority of the generic low-degree discrepancy lemma and its applications is NOT verified.
