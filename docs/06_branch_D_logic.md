# Branch D — Linear Monadic NP, MSO2 and global rank

Ganian, de Haan, Kanj and Szeider, On Existential MSO and Its Relation to ETH (MFCS 2016; TOCT 2020), define Linear Monadic NP, show subexponential-time equivalences with fixed-width SAT for some graph problems (including Dominating Set and Perfect Code), and discuss the non-definability of Feedback Vertex Set in their existential-monadic formalism.

Thus Dominating Set cannot be treated as an untouched survivor of fixed-width SAT acceleration under the same n-vertex measure. MSO1 inexpressibility of FVS is not an unrestricted Boolean-circuit lower bound.

## Candidate expressive separator
A fixed local existential-monadic formula plus one single global graphic-matroid rank condition. Compare:
- existential MSO1 and Linear Monadic NP;
- existential MSO2 with fixed formulas that quantify edge sets;
- rank-augmented monadic NP and restrictions by bounded degree/sparse incidence.

Carefully keep the logical sentence fixed when measuring data complexity, and count representation cost if the formula grows. Search for expressibility collapses on bounded-degree graphs.
